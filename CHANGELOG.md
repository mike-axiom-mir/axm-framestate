# Changelog

## v0.2 development checkpoint

Expanded the initial procedural renderer into a genre-open video construction body:

- v0.2 canonical schema alongside v0.1 compatibility;
- multi-keyframe curves;
- imported image/video media conforming with source + conformed-frame receipts;
- image/video layers, playback speed, trim/loop, fades and blend modes;
- deterministic bitmap text and burned captions;
- WebVTT export;
- imported audio decoding/mixing;
- optional eSpeak narration boundary;
- shot markers, shot derivation and storyboard contact sheets;
- structured shot-plan compiler;
- render queues;
- fixed-point primitive 3D;
- OBJ mesh import and animated rasterization;
- richer capability/gap map.

The four roots and one-chat/one-PR collaboration lane remain unchanged.
